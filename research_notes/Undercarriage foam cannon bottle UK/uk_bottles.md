## 1. Common bottle neck thread on generic brass-knob foam cannons

### Takeaway
The clearest evidence points to **28mm (28/400 or 28-410 style)** as the near-universal neck thread on generic Chinese brass-body foam cannons. No source mentioned 38mm or 48/50mm necks for this style. "Wide mouth" bottles (MTM PF22.2, Armour DRFT) are brand-specific and some need an adapter, so they are not the generic standard.

### Cited Findings
- In the DetailingWorld UK thread "Foam lance bottle thread size", a user reports that "most if not all lances are 28mm thread", with one older Autobrite lance measuring 27mm. Another commenter says they "pretty much all have the same 28/400 neck threading" (anecdotal). In the same thread, a bottle sold as 28mm turned out "maybe 0.5/1mm bigger" than the original, so a 28mm label does not guarantee a fit. — [DetailingWorld](https://www.detailingworld.co.uk/threads/foam-lance-bottle-thread-size.379210/) (seen via search snippet only; page not fetched)
- The MTM Standard replacement bottle (1L) lists thread size **28-410**. — [Auto Obsessed – MTM Standard Replacement Bottle](https://www.autoobsessed.com/products/foam-cannon-bottle-replacement)
- MTM sells a "PF22 foamer bottle (narrow neck)", and one MTM listing gives "Diameter: 22 MM". That figure probably names the PF22 model or a body dimension rather than the neck thread, since the snippet does not say. It conflicts with the 28-410 spec above and is unresolved. — [MTM Hydro foam cannons](https://www.mtmhydroparts.com/collections/foam-cannons)
- The MTM wide-mouth bottle (PF22.2) "on its own will not work with older foam cannons without the black adapter". Wide-mouth is therefore a different, non-generic thread. — [Clean Garage](https://clean-garage.com/mtm-wide-mouth-foam-cannon-bottle-pf22-2-bottle-only-no-adapter/); [eBay MTM kit](https://www.ebay.com/itm/176263898546)
- A DI Accessories reviewer reported that the original-model bottle fits both cannons "as long as it is not the wide mouth version". — [Detailed Image](https://www.detailedimage.com/DI-Accessories-M12/MTM-Hydros-PF22-Stand-Up-Replacement-Bottle-P3107/)
- SudMagic says generic cannons have plastic-threaded bottles screwed into a brass head, so the bottle threads strip quickly. — [SudMagic](https://sudmagic.com/products/foam-cannon-car-wash-gun)
- AutoGeek has threads about replacing broken cannon bottle necks with cheap generic bottles (titles only seen). — [AutoGeek 1](https://autogeekonline.net/threads/broke-the-neck-of-my-foam-cannon-bottle-again-awesome-replacement-tip-trick.109897/); [AutoGeek 2](https://www.autogeekonline.net/forum/tricks-tips-and-techniques/125644-cheap-foam-cannon-bottle-replacement.html)

### Inferences
- The inline cannon on ADCR / Tool Daily / Twinkle Star / RIDGE WASHER undercarriage cleaners looks like the same generic brass-knob head (same OEM style), so its bottle is very likely a ~28mm thread. This has not been measured. The user should check the neck outside diameter with calipers (about 27.5–28.5mm points to 28/400 or 28/410).
- Avoid "wide mouth" bottles (MTM PF22.2, Armour DRFT, MJJC S V3.0 bottles) unless they come with an adapter, and avoid bayonet bottles (MJJC Pro V3), because they are not the generic thread.

### Gaps
- I found no manufacturer spec giving the neck thread for the Tool Daily, Twinkle Star, RIDGE WASHER or ADCR undercarriage inline cannon.
- I found no measured 38mm or 48/50mm neck for generic cannons in any source.
